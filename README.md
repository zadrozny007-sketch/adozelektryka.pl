# adozelektryka.pl

Strona AdoZ Auto, elektryk samochodowy w Osiecku. Stoi na GitHub Pages z domeną adozelektryka.pl (plik `CNAME`).

## Jak zmieniać stronę

Strony HTML są generowane skryptem `_narzedzia/build.py`: nagłówek, stopka, menu, formularze i treść wszystkich podstron. Zmieniaj treść w skrypcie, uruchom go i wrzuć zmiany:

```
python3 _narzedzia/build.py
```

Ręczne poprawki w plikach `.html` zostaną nadpisane przy następnym uruchomieniu skryptu.

Poza skryptem: `style.css` (wygląd), `main.js` (menu i formularze), `favicon.svg`.

## Formularze

GitHub Pages nie obsługuje PHP, więc formularze niczego nie wysyłają same. Składają wiadomość i otwierają WhatsApp na numer 511 933 675 (`WA_NUM` w skrypcie).

## Zasady treści

Bez cen, bez wymyślonych opinii i liczb. Nic o usuwaniu DPF, EGR i AdBlue, DTC off, immo off ani korekcie licznika. Bez nazw urządzeń i bez „autoryzowanego serwisu”.
